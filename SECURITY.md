# Security policy

## Supported versions

Security fixes target the latest stable release of the macOS host and Windows viewer. Check the [GitHub releases page](https://github.com/Uraniumking007/remote-mac/releases/latest) for the current version. Reports about older versions are welcome if the issue may still affect the current release.

## Report a vulnerability

[Report a vulnerability privately on GitHub](https://github.com/Uraniumking007/remote-mac/security/advisories/new). Use that form for suspected vulnerabilities in the host, viewer, pairing, or release and update process. Keep vulnerability details out of public issues and discussions.

Include the affected component and app version, the macOS or Windows version, the conditions needed to trigger the issue, reproduction steps, and the potential impact. Use devices you own or have permission to test. Redact pairing keys, private keys, credentials, and personal data from logs and screenshots.

Please keep technical details private while maintainers investigate and coordinate a fix and any public advisory. Use the private GitHub report for follow-up.
